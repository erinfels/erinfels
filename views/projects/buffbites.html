Buff Bites

Create or recreate a

Overview:

Group Project created for Software Development Methods and Tools. Our final assignment was to design an application that does not exist or redesign a website that could use new features and/or UI/UX. We created Buff Bites. The project was completed with

Buff Bites is a replacement for CU’s current online menu app Nutrislice. It has the menu for every dining location on campus. Buff Bites also has a convenient menu layout, allows users to search for and filter items, and has a profile feature that lets users favorite items. Buff Bites pulls its menu data straight from Nutrislice which makes it a feature complete replacement.
