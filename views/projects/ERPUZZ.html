Escape Room Puzzle

Created an Escape Room Puzzle for a physical computing class project to combine physical fabrication and circuit design

Overview:

We were able to choose to do a project that combined electrical components and enclosure design. I chose to create my own escape room puzzle. This puzzle used 3 RFID tag readers and included code that made sure that the correct tag was placed. It linked to a boolean statement that triggered a servo to the move to the open position. If not, it would move back to zero or stay at the zero position. I used a hinge and prints from Printables (all linked below).
