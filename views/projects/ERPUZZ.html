Escape Room Puzzle

About:

We were able to choose to do a project that combined electrical components and enclosure design. I chose to doan escape room puzzle. This puzzle used 3 RFID tag readers and included code that made sure that the correct tag was placed. It linked to a boolean statement that triggered a servo to the move to the open position. If not, it would move back to zero or stay at the zero position. I used a hinge and prints from Printables (all linked below).

Working prototype where a light turns on first. I worked with each component individually first and then integrated them later.
